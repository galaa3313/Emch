# Анатоми 3D — хүний биеийн атлас ба сургалт

Монгол хэл дээрх хүний биеийн 3D атлас, мөн биологи, химийг анхан шатнаас анагаахын суурь хүртэл алхам алхмаар заадаг «Сурах» хэсэг.
Утсанд апп шиг суулгаж, интернэтгүй ашиглаж болно (PWA).

## Бүтэц
| Файл / хавтас | Юу вэ |
|---|---|
| `index.html` | Үндсэн хуудас (атлас: хүний бие, нүд, ургийн хөгжил, өвдөлт) |
| `learn/` | Сурах хэсэг: `data-1/2/3.js` — 37 хичээл (3 түвшин × биологи, хими), `viewer3d.js` — эс, митохондри, молекул, атомын 3D, `learn.js` — дэлгэц, шалгалт, явц |
| `lib/` | three.js r147 (MIT лиценз) |
| `data/` | Хүний биеийн 3D өгөгдөл (BodyParts3D, CC BY-SA 2.1 JP) |
| `manifest.webmanifest`, `sw.js`, `icons/` | Апп болгон суулгах, оффлайн ажиллах тохиргоо |

## GitHub Pages дээр байршуулах
1. GitHub дээр шинэ repository үүсгэ (жишээ нь `anatomy-3d`, **Public**).
2. **Add file → Upload files** дарж энэ хавтасны **бүх файл, хавтсыг** чирж оруулаад **Commit changes** дар.
   (`index.html` repository-ийн үндсэн хавтсанд байх ёстой.)
3. **Settings → Pages → Build and deployment → Source: Deploy from a branch**, Branch: `main`, хавтас: `/ (root)` → **Save**.
4. 1–2 минутын дараа `https://<таны-нэр>.github.io/anatomy-3d/` хаягаар нээгдэнэ.

## Утсанд апп болгон суулгах
- **Android (Chrome):** хуудсыг нээгээд цэс (⋮) → **Апп суулгах / Add to Home screen**.
- **iPhone (Safari):** **Share** → **Add to Home Screen**.
- Нэг удаа интернэттэй нээхэд бүх файл хадгалагдана (~8 МБ). Дараа нь интернэтгүй ажиллана.

## Шинэчлэх
Файлаа өөрчлөөд дахин upload хийсний дараа `sw.js` доторх `VERSION = 'anat-v1'`-ийг `anat-v2` гэх мэтээр нэмэгдүүлбэл хэрэглэгчдийн утсанд шинэ хувилбар очно.
